# Healthcare Data Insights and Readmission Prediction Model

This project covers the generation of a sample healthcare dataset simulating patient information, including age, department, length of stay, comorbidities, and readmission status. It provides data overview and cleaning steps to ensure data quality, followed by descriptive statistical analysis to summarize key metrics. The code includes visualizations such as bar plots for readmission rates by department and box plots for average length of stay across age groups, offering insights into nursing outcomes. Additionally, it features a predictive analysis section using logistic regression to forecast patient readmissions, with model evaluation based on accuracy to support data-driven decision-making in healthcare settings.
